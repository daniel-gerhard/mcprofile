model coefficients

  : Construction of Multiple Contrast Profiles
- [`confint(`*`<mcprofile>`*`)`](https://daniel-gerhard.github.io/mcprofile/reference/confint.mcprofile.md)

- [`summary(`*`<mcprofile>`*`)`](https://daniel-gerhard.github.io/mcprofile/reference/summary.mcprofile.md)

## Profile statistics

- [`wald()`](https://daniel-gerhard.github.io/mcprofile/reference/wald.md)
  : Calculate Wald-Profiles
- [`hoa()`](https://daniel-gerhard.github.io/mcprofile/reference/hoa.md)
  : Higher order asymptotics using the modified likelihood root
